SOURCES & METHODOLOGY

Live public data, not simulated. Earthquakes use USGS GeoJSON; weather alerts use NWS; fire, flood, and storm events use NASA EONET. These are different observation and publication systems, not an exhaustive U.S. incident registry.

The OQLIV news JSON API aggregates publisher RSS and news discovery server-side. SITREP shows all OQLIV headlines under OQLIV NEWS, but places map pins only for incident-related headlines with supported locations. Other news does not count as a mapped incident. Original article links are preserved. The app no longer tries browser-side Google News, GDELT, or publisher RSS proxies because these frequently fail due to CORS or rate limits. The OQLIV collector handles ingestion upstream. A news article is not a verified active incident; locations are approximate if inferred from headlines.

Map outlines and state boundaries are embedded offline from GSHHS / Basemap. No tile server or map API key. This is not an emergency dispatch tool; follow official warnings and local authorities.
